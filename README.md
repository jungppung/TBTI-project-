# 📱 TBTI (Travel Based Type Indicator)
> 예산과 일정 기반의 여행 구매력 예측 및 가이드 서비스
---
## 1. 프로젝트 소개
본 서비스는 사용자가 입력한 예산과 일정을 바탕으로, 가고 싶은 목적지에서 어느 정도 수준의 소비가 가능할지** 재정적 지속 가능성을 객관적으로 예측하고 분석(시뮬레이션) **해주는 서비스입니다.

---

## 2. 기획 배경 및 핵심 타겟층

### 💡 기획 배경
* **막연한 여행 기획의 데이터 기반 구체화:** 해외여행을 계획할 때 "내가 가진 가용 예산으로 해당 국가에서 어느 정도의 소비가 가능할까?"라는 막연한 의문을 실시간 변동 환율과 현지 물가지수 데이터를 기반으로 정량화하여 빠르게 시뮬레이션하고자 합니다.
* **예산 수립의 심리적 진입장벽 완화:** 복잡한 자금 계획서나 영수증 역추산 없이도, 단 1분 만에 목적지에서의 **재정적 지속 가능성과 소비 클래스를 예측**할 수 있는 신속한 인프라를 제공합니다.

### 📌 핵심 타겟층
* **⏳ 가볍고 빠른 예산 기획자:** 구체적인 계획을 짜기 전, "내가 가진 예산으로 이 나라를 갈 수 있을까?"를 단 1분 만에 빠르게 시뮬레이션해보고 싶은 여행자
* **🎒 여행 예산 감각이 부족한 초보자:** 대학생 및 배낭 여행족 등 한정된 비용으로 최대의 효율을 내야 하는 여행자
* **🗺️ 지갑 사정 맞춤형 활동을 원하는 사람:** 내 구매력 수준에 딱 맞는 로컬 활동 추천을 한눈에 보고 싶은 여행자

---

## 3. 프로젝트 목표 (Goals)
본 프로젝트는 사용자가 막연하게 느끼는 해외 여행 비용을 데이터 기반으로 시뮬레이션하여, 현실적이고 직관적인 가이드라인을 제공하는 것을 목표로 합니다.

* **💰 목적지별 '지갑 사정 및 여행 구매력'의 정교한 진단**
    * 외부 API 스케줄링 캐싱을 통한 실시간 환율과 현지 5개 도시의 물가 통계 상수를 결합하여, 사용자가 입력한 원화 예산이 현지에서 가질 **'실질 구매력'을 백엔드에서 오차 없이 계산하고 예측**합니다.
* **🎭 비직설적 UX를 통한 '예산 체감도' 극대화**
    * "예산 부족/과잉"이라는 단순하고 딱딱한 수치 표현 대신, 계산된 구매력을 **8가지 위트 있는 캐릭터 페르소나 유형**으로 변환하여 제공합니다. 이를 통해 사용자가 거부감 없이 자신의 현재 지갑 사정을 직관적이고 유쾌하게 체감하도록 유도합니다.
* **✨ 개인화된 여행 액션 플랜(가이드) 제공**
    * 단순 지갑 사정 진단에 그치지 않고, 도출된 구매력 수준과 유저의 활동 성향(정적/동적)을 고려한 **맞춤형 활동 추천(Bored API 활용) 및 북마크 저장 기능**을 연동하여 실질적으로 기능하는 여행 인프라 가이드 플랫폼을 구축합니다.

* **Database:** MySQL
* **Frontend:** Android Studio (Java)
